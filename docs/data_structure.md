# ساختار داده

## ۱. مسیر کلی داده در گروه

```
Hugging Face (GTZAN)
        │  دانلود دستی ۱۴ فایل
        ▼
data/genres_original/<genre>/<file>.wav        ← فایل‌های صوتی خام
        │  src/load_data.py            (بخش کد: ویسه)
        ▼
data/processed/metadata.csv                    ← فهرست فایل‌ها
        │  src/data_evaluation.py      (بخش داده و ارزیابی: حیدری)
        ▼
data/processed/clean_metadata.csv              ← فهرست پاک‌شده
data/processed/train.csv                       ← مجموعه آموزش
data/processed/test.csv                        ← مجموعه آزمون
data/processed/quality_report.json             ← گزارش کیفیت
```

اسکریپت‌های این مخزن (`src/inspect_audio.py` و `src/mirror_inventory.py`) چیزی را در مسیر بالا تغییر نمی‌دهند و فقط ساختار و مشخصات داده را ثبت می‌کنند.

## ۲. ساختار پوشه‌ها

```
data/
├── genres_original/          فایل‌های صوتی، یک پوشه برای هر ژانر
│   ├── blues/
│   │   ├── blues.00000.wav
│   │   ├── blues.00002.wav
│   │   └── blues.00003.wav
│   ├── classical/
│   ├── hiphop/
│   ├── jazz/
│   └── rock/
└── processed/                فایل‌های ساخته‌شده با اسکریپت‌ها
    ├── metadata.csv
    ├── clean_metadata.csv
    ├── train.csv
    ├── test.csv
    └── quality_report.json
```

- **برچسب هر فایل از نام پوشه‌اش گرفته می‌شود.** فایل جداگانه‌ای برای برچسب‌ها وجود ندارد.
- نام پوشه‌ها با حروف کوچک انگلیسی است و همان نام ژانر در کد و خروجی‌هاست.

## ۳. قاعده نام‌گذاری فایل‌ها

```
<genre>.<index>.wav
```

| بخش | توضیح | مثال |
|---|---|---|
| `genre` | نام ژانر با حروف کوچک، همان نام پوشه | `hiphop` |
| `index` | شماره قطعه در آن ژانر، ۵ رقمی با صفر در ابتدا، از `00000` تا `00099` | `00013` |
| پسوند | همیشه `.wav` | |

مثال: `hiphop.00013.wav` یعنی قطعه شماره ۱۳ ژانر هیپ‌هاپ.

شماره‌ها پشت سر هم نیستند، چون بعضی قطعه‌ها در نسخه Hugging Face وجود ندارند (مثلاً `blues.00001.wav`). فهرست کامل شماره‌های غایب در `data/mirror_summary.json` است.

## ۴. مشخصات فنی فایل‌های صوتی

این مقادیر با `src/inspect_audio.py` از روی هر ۱۴ فایل موجود اندازه‌گیری شده‌اند:

| ویژگی | مقدار اندازه‌گیری‌شده | مقدار مورد انتظار GTZAN | وضعیت |
|---|---|---|---|
| قالب | WAV (PCM) | WAV | ✔ |
| نرخ نمونه‌برداری | ۲۲۰۵۰ هرتز | ۲۲۰۵۰ هرتز | ✔ |
| تعداد کانال | ۱ (تک‌کاناله) | ۱ | ✔ |
| عمق بیت | ۱۶ بیت | ۱۶ بیت | ✔ |
| طول | ۳۰٫۰۰۰ تا ۳۰٫۰۱۳ ثانیه | حدود ۳۰ ثانیه | ✔ |
| تعداد نمونه در هر فایل | حدود ۶۶۱٬۸۰۰ | ۲۲۰۵۰ × ۳۰ | ✔ |
| حجم هر فایل | حدود ۱٫۳ مگابایت | | |
| حجم کل ۱۴ فایل | ۱۸٫۵ مگابایت | | |
| فایل تکراری (SHA-256 یکسان) | ندارد | | ✔ |

**نتیجه:** هر ۱۴ فایل با مشخصات GTZAN یکسان‌اند و بدون تبدیل قالب یا نرخ نمونه‌برداری قابل استفاده‌اند.

برای کل دیتاست: هر قطعه ۳۰ ثانیه × ۲۲۰۵۰ = حدود ۶۶۱ هزار عدد ۱۶ بیتی است. اگر در گام‌های بعد قطعه‌ها به بخش‌های ۳ ثانیه‌ای بریده شوند، هر قطعه ۱۰ نمونه آموزشی می‌دهد.

## ۶. فرهنگ داده (Data Dictionary)

### `metadata.csv`، `clean_metadata.csv`، `train.csv`، `test.csv`

هر چهار فایل ستون‌های یکسانی دارند. کدگذاری `UTF-8` با BOM (`utf-8-sig`) است تا در Excel درست باز شود.

| ستون | نوع | توضیح | مثال |
|---|---|---|---|
| `file_name` | متن | نام فایل صوتی | `rock.00003.wav` |
| `file_path` | متن | مسیر فایل نسبت به پوشه اصلی پروژه، با `/` | `data/genres_original/rock/rock.00003.wav` |
| `genre` | متن (برچسب) | ژانر، یکی از ۱۰ ژانر GTZAN با حروف کوچک | `rock` |

**نکته:** `metadata.csv` در مخزن ویسه مسیر کامل ویندوزی دارد (مثلاً `D:\daneshgah\...\blues.00000.wav`) و روی سیستم دیگری کار نمی‌کند. حیدری در مخزن خودش آن را به مسیر نسبی تبدیل کرده است. پیشنهاد: `load_data.py` هم مسیر نسبی بنویسد (`audio_file.relative_to(PROJECT_DIR).as_posix()`).

### `quality_report.json`

| کلید | توضیح |
|---|---|
| `input_rows` | تعداد ردیف ورودی |
| `kept_rows` | تعداد ردیف سالم |
| `discarded_rows` | تعداد ردیف کنارگذاشته‌شده |
| `train_rows` / `test_rows` | تعداد نمونه آموزش و آزمون |
| `genre_counts` | تعداد نمونه هر ژانر |
| `train_genre_counts` / `test_genre_counts` | تعداد نمونه هر ژانر در آموزش و آزمون |
| `test_coverage_complete` | آیا همه ژانرها در آزمون هستند |
| `discarded` | فهرست ردیف‌های کنارگذاشته‌شده و دلیل آن |
| `mode` | `metadata_only` (فقط فهرست بررسی شده) یا `audio_checked` |
| `seed` / `requested_test_ratio` | تنظیمات تقسیم داده |
| `warnings` | هشدارها |
